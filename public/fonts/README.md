# Optional local fonts

Custom font binaries are intentionally excluded from this public repository because their redistribution licenses may vary.

If you have the appropriate rights, place the following files in this directory:

- `pingfang-shiguang.ttf`
- `pingfang-shaohua.ttf`
- `pingfang-satuo.ttf`
- `yangren-dongzhu-bold.ttf`
- `pingfang-jiangjun.ttf`
- `pingfang-shoushu.ttf`

The application remains usable without them and falls back to the built-in or system fonts.
